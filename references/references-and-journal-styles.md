## Reference Integrity

All references used in Introduction or Discussion writing must pass pool-first
verification (see `SKILL.md ## Reference Verification`). The rules below apply
to all modes.

- Never invent or silently complete author lists, years, titles, journals,
  volumes, pages, article numbers, or DOIs.
- A reference is verified when its DOI resolves and title, author list, and year
  are confirmed. Unverified references must not appear in manuscript output.
- Keep a clear boundary between verified pool references, user-supplied but
  unchecked references, and candidate literature requiring review.
- If the user supplies a reference manually, verify it through the same
  PubMed → Crossref → Semantic Scholar pipeline before using it.
- When DOI metadata cannot be confirmed after all three tiers, exclude the
  reference and note the gap to the user.

## Introduction and Discussion Literature

For each load-bearing source, know:

- what claim it supports;
- what it does not support;
- how close it is to the target population, variables, and design;
- whether it belongs in background, gap, comparison, mechanism, limitation, or
  implication writing.

## APA Default

When no journal style is supplied:

- use APA-style in-text citations and reference-list structure;
- check that every in-text citation has a matching reference-list entry;
- check that every reference-list entry is used or intentionally retained;
- provide DOI details in a verifiable form when available.

## Journal Adaptation

When the user supplies author guidelines, examples, or a recent article:

1. extract the citation and reference pattern;
2. distinguish journal-specific order, punctuation, abbreviation, DOI, and
   issue/page rules from APA defaults;
3. transform the references without guessing missing metadata;
4. note any unresolved metadata or style ambiguity.
